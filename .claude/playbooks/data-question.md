### Data question

**You own the number's provenance.** The four-lane Stop gate reads the transcript, not narration — the searches are real tool calls made BEFORE the first word.

1. RESEARCH lane — `_RESEARCH/INDEX.md` for the topic; open the hit.
2. CATALOG lane — `docs/standards/data-roots.md` top section: which root serves this concept, its cadence, 🔴/🟡/🟢. A 🔴 root is the intended home, never a served number (RULE 0.55).
3. CODE lane — the producer that owns the number (graph `graphify_find` → open the file). Read rates as written; never recompute a rate from raw counts (protocol v3 §4).
4. LIVE lane — fetch `https://www.swfldatagulf.com/api/b/master?view=speak&tier=2&v=5`; route to the upstream brain it names at the same tier; quote `freshness_token` verbatim once, as MM/DD/YYYY.
5. Domain rules before quoting: sold price = deed record, never list; comps are size-banded same-type (condo ≠ SFH); situs ZIP, never mailing (memory: real-estate-domain-rules).
6. A gap is filled from the next lane, never invented and never refused: our data → user's upload → named web source → the user's own figure (RULE 0.7). Only an invented number blocks.
7. Sources disagree → say "X verified, Y needs review" (global rule 4). Projections carry `[INFERENCE]`, the audited base, one falsifier.
8. Before speaking any count or percentage from our own tables: `count=planned` is an estimate; aggregate at source, not fetched rows (memory refs).

**Rules carried:** FOUR-LANE gate · protocol v3 §1–8 · RULE 0.55 · RULE 0.7 · FOCUS 1/2/3/8 · real-estate domain rules.

**Reply:** the number(s) with root + as-of date, plain text, no tables, no pack ids; discrepancies surfaced; what you could not source and which lane is open.
