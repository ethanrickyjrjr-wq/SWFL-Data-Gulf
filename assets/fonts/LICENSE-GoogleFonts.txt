SIL OPEN FONT LICENSE 1.1 — bundled Google Fonts faces
======================================================

These faces are vendored so server-side chart rasterization (resvg) renders in the
AGENT'S OWN BRAND FONT rather than a single fixed Arial clone. See lib/brand/fonts.ts
(canvasFamily / canvasFiles) for which brand maps to which face, and
lib/brand/canvas-fonts.test.ts for the guards.

Every face below is licensed under the SIL Open Font License, Version 1.1, which
permits bundling and redistribution with or without modification, provided the fonts
are not sold by themselves and this notice is retained. Full license text:
https://openfontlicense.org  ·  Upstream: https://github.com/google/fonts

Files were pulled 08/06/2026 as STATIC Regular (400) / Bold (700) instances from the
Google Fonts css2 endpoint, which serves per-weight TTFs to a legacy user agent. Static
instances are deliberate: resvg 2.6.2 does not apply variable-font weight axes, so a
variable file would render every bold chart title at regular weight.
